# 🏦 Tinkoff Transaction Analyzer (Sky Shop)

Промышленный прототип банковского шлюза для анализа и управления транзакциями. Проект построен по стандартам Middle-разработки 2026 года.

## 🚀 Что реализовано (Чек-лист 1-2 марта)

### 🧱 Архитектура и Инфраструктура
*   **Профессиональная структура**: Логика вынесена в пакет `src/`, точка входа — в корневом `main.py`.
*   **Окружение**: Настроена виртуальная среда `.venv` и сформирован `requirements.txt`.
*   **Git-контроль**: Настроены ветки (`main`, `start-code`) и синхронизация с GitHub.

### 🛡️ Безопасность и Логика (ООП)
*   **Инкапсуляция**: Сумма транзакций защищена через приватный атрибут `_amount` и доступна только для чтения через `@property`.
*   **Валидация**: Внедрена проверка типов через `isinstance` при добавлении в историю банка.
*   **Промышленный запуск**: Использована конструкция `if __name__ == "__main__": sys.exit(main())` для безопасного исполнения.

### 💎 Качество кода (QA)
*   **Строгая типизация**: Весь код покрыт Type Hinting (`str`, `float`, `list[Transaction]`) для проверки через `mypy`.
*   **Авто-форматирование**: Применены стандарты `black` и `isort`.
*   **Линтинг**: Код прошел проверку `flake8` с кастомной настройкой длины строки (119 символов).

## 🛠️ Как запустить
1. Установить зависимости: `pip install -r requirements.txt`
2. Запустить линтер: `flake8 .`
3. Запустить проверку типов: `mypy . --explicit-package-bases`
4. Запустить приложение: `python main.py`
